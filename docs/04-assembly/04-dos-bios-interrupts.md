# DOS 与 BIOS 中断

DOS 和 BIOS 以中断形式提供系统服务，汇编程序通过 `INT n` 调用，功能号放入 AH，参数放入其他寄存器。

---

## 一、中断分类

| 类型 | 中断号 | 说明 |
| :--- | :--- | :--- |
| DOS 中断 | INT 21H | 功能最丰富，字符/字符串输入输出、文件、退出等 |
| BIOS 中断 | INT 10H | 视频显示服务 |
| BIOS 中断 | INT 16H | 键盘服务 |
| BIOS 中断 | INT 13H | 磁盘服务 |
| 其他 | INT 20H、INT 27H | 老式退出/驻留 |

---

## 二、INT 21H 常用功能

| AH 功能号 | 功能 | 入口参数 | 返回 |
| :---: | :--- | :--- | :--- |
| 01H | 带回显键盘输入一个字符 | 无 | AL=输入字符 |
| 02H | 输出一个字符 | DL=字符 | 无 |
| 07H/08H | 无回显键盘输入 | 无 | AL=字符 |
| 09H | 输出字符串 | DS:DX=串首，以 `$` 结束 | 无 |
| 0AH | 输入字符串到缓冲区 | DS:DX=缓冲区 | 缓冲区内为输入 |
| 25H/35H | 设置/取得中断向量 | AL=类型号 | 无/ES:BX |
| 4CH | 程序退出 | AL=返回码 | 无 |

### 1. 单字符输出

```asm
MOV DL, 'A'
MOV AH, 02H
INT 21H
```

### 2. 输出字符串

```asm
LEA DX, MSG
MOV AH, 09H
INT 21H
MSG DB 'Hello $'
```

### 3. 单字符输入

```asm
MOV AH, 01H
INT 21H            ; AL 中得到按键字符
```

### 4. 字符串输入（0AH）

缓冲区结构：

```text
第 0 字节：最大可输入字符数
第 1 字节：实际输入字符数（系统回填）
第 2 字节起：实际字符
```

```asm
DATA SEGMENT
    BUF DB 20, ?, 20 DUP(?)
DATA ENDS
LEA DX, BUF
MOV AH, 0AH
INT 21H
```

---

## 三、INT 10H 视频服务常用功能

| AH | 功能 |
| :---: | :--- |
| 00H | 设置显示模式（如 03H 为 80×25 文本） |
| 02H | 设置光标位置（DH=行，DL=列，BH=页） |
| 06H/07H | 屏幕上滚/下滚（清屏） |
| 09H | 在光标处写字符及属性 |
| 0EH | 电传方式写字符 |

清屏示例：

```asm
MOV AH, 06H
MOV AL, 0          ; 整屏
MOV CX, 0
MOV DX, 184FH
MOV BH, 07H
INT 10H
```

---

## 四、INT 16H 键盘服务

| AH | 功能 |
| :---: | :--- |
| 00H | 读键盘字符，AX=扫描码/字符码 |
| 01H | 检测有无按键，ZF 反映状态 |

---

## 五、调用约定小结

1. 功能号放 AH
2. 按要求在 DX/DL/AL 等寄存器准备参数
3. 执行 INT n
4. 从指定寄存器取返回结果

---

## 六、小结

- INT 21H 是 DOS 系统调用主力，重点掌握 01/02/09/0A/4C
- INT 10H 管显示、INT 16H 管键盘
- 中断调用让汇编程序能方便地完成输入输出
