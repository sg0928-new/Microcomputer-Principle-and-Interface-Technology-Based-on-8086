# 实验一：LED 流水灯（8255A 方式 0 输出）

## 一、实验目的

1. 掌握 8255A 可编程并行接口的初始化方法
2. 理解方式 0（基本输入输出）的工作过程
3. 学会用循环移位指令实现流水灯效果

## 二、实验原理

8255A 的 PA 口工作在方式 0 输出，PA0~PA7 各接一个发光二极管。CPU 向 PA 口输出数据，输出位为 1 时对应 LED 点亮。通过 `ROL` 循环左移并配合软件延时，使点亮的 LED 依次移动，形成流水效果。

## 三、端口地址分配（由 74LS138 译码）

| 端口 | 地址 |
| :--- | :--- |
| PA | 300H |
| PB | 301H |
| PC | 302H |
| 控制寄存器 | 303H |

## 四、控制字计算

PA、PB、PC 均为方式 0 输出：

```text
D7=1（方式控制字标志）
D6D5=00（A组方式0） D4=0（PA输出） D3=0（PC高4位输出）
D2=0（B组方式0）   D1=0（PB输出） D0=0（PC低4位输出）
控制字 = 10000000B = 80H
```

## 五、接线表

| 8255A 引脚 | 连接 |
| :--- | :--- |
| PA0~PA7 | 经限流电阻接 8 个 LED 阳极 |
| LED 阴极 | 接地（GND） |
| RD | 8086 RD |
| WR | 8086 WR |
| A0/A1 | 8086 地址总线 A0/A1 |
| CS | 地址译码输出（对应 300H~303H） |

## 六、实验步骤

1. 在 Proteus 中按接线表连接电路
2. 汇编 `led_flow.asm`，生成可执行/二进制文件并加载到 8086
3. 运行，观察 8 个 LED 依次循环点亮
4. 修改延时循环初值，观察流水速度变化

## 七、思考与扩展

- 若要改为从右向左流动，应使用哪条移位指令？（`ROR`）
- 若 LED 改为低电平点亮，输出数据应如何处理？（初始值改为 `FEH`，取反逻辑）
