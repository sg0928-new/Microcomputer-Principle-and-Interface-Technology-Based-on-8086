# 中断向量表

## 一、向量表的结构

中断向量表位于内存**最低端 0000:0000 ~ 0000:03FFH**，共 1KB，存放 256 个中断向量。

- 每个中断向量占 **4 字节**：低 2 字节为偏移地址 IP，高 2 字节为段地址 CS
- 256 个类型号：0 ~ 255（00H ~ FFH）

```text
类型号 n 的向量地址 = n × 4
┌──────────────┬──────────────┐
│ 0000: n×4    │ 偏移 IP（2字节）│
│ 0000: n×4+2  │ 段地址 CS（2字节）│
└──────────────┴──────────────┘
```

---

## 二、类型号与向量地址

| 类型号 | 用途 | 向量地址（0000:） |
| :---: | :--- | :--- |
| 0 | 除法错 | 0000H |
| 1 | 单步 | 0004H |
| 2 | NMI | 0008H |
| 3 | 断点 | 000CH |
| 4 | 溢出 | 0010H |
| 5~7 | 保留 | 0014H~001CH |
| 8~FH | 8259A 硬件中断 | 0020H~003CH |
| 10H | 视频 | 0040H |
| 16H | 键盘 | 0058H |
| 21H | DOS 功能调用 | 0084H |

---

## 三、地址计算示例

类型号 `21H`：

```text
向量地址 = 21H × 4 = 0084H
0000:0084H 存 IP
0000:0086H 存 CS
```

---

## 四、中断向量的读取与设置

### 1. INT 21H 的 35H（取向量）

```asm
MOV AL, 21H
MOV AH, 35H
INT 21H            ; ES:BX = 原中断向量
```

### 2. INT 21H 的 25H（设置向量）

```asm
MOV AX, SEG MY_INT
MOV DS, AX
MOV DX, OFFSET MY_INT
MOV AL, 60H
MOV AH, 25H
INT 21H            ; 把 60H 号向量指向 MY_INT
```

### 3. 编写自己的中断处理程序（典型结构）

```asm
MY_INT PROC FAR
    PUSH AX
    ; ... 处理 ...
    MOV AL, 20H
    OUT 20H, AL     ; 向 8259A 发 EOI 命令
    POP AX
    IRET
MY_INT ENDP
```

---

## 五、接管中断的注意事项

1. 先保存原向量（35H），程序退出前恢复，避免系统异常
2. 改变向量前确保 DS 正确
3. 硬件中断服务程序结束要发 EOI（`OUT 20H,20H`）
4. 中断服务程序应尽量短小、避免重入

---

## 六、小结

- 向量表在内存最低 1KB，256 个向量，每个 4 字节（IP+CS）
- 向量地址 = 类型号 × 4
- 用 INT 21H 的 25H/35H 设置/读取向量
- 自定义中断通过 IRET 返回，硬件中断需发 EOI
