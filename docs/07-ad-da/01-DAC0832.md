# DAC0832 数模转换器

DAC0832 是 8 位、采用 CMOS 工艺、带双缓冲输入寄存器的数模转换芯片，可将 8 位数字量转换为模拟电流（外接运放得到电压）。

---

## 一、主要特性

- 8 位分辨率，电流输出型
- 双缓冲、单缓冲、直通三种工作方式
- 与微处理器总线兼容，可直接挂接数据总线
- 单一 +5V，参考电压可正可负（±10V 内）
- 20 引脚

---

## 二、内部结构

```text
D0~D7 ──► 输入寄存器 ──► DAC寄存器 ──► 8位D/A转换电路 ──► Iout1/Iout2
         ILE/CS/WR1        WR2/Xfer
```

两级寄存器使数据写入与实际转换可分开控制，便于多路同步输出。

---

## 三、关键引脚

| 引脚 | 功能 |
| :--- | :--- |
| D0~D7 | 8 位数据输入 |
| ILE | 输入锁存允许（高有效） |
| CS | 片选（低有效） |
| WR1 | 写输入寄存器 |
| WR2 | 写 DAC 寄存器 |
| XFER | 传送控制（低有效） |
| Iout1 / Iout2 | 电流输出 |
| Rfb | 片内反馈电阻端 |
| Vref | 参考电压 |

---

## 四、三种工作方式

### 1. 直通方式

所有控制信号有效，数据直接进入 D/A 转换，无锁存。

### 2. 单缓冲方式

两级寄存器中一级处于直通、另一级受控，一次写操作即完成转换，最常用。

### 3. 双缓冲方式

先写输入寄存器，再统一触发 DAC 寄存器，适合多片 DAC 同步输出。

---

## 五、输出关系

```text
Vout = − (D / 256) × Vref
```

其中 D 为输入数字量（0~255）。

| 数字量 | 输出（Vref=5V） |
| :---: | :--- |
| 00H | 0V |
| 80H | −2.5V |
| FFH | −4.98V |

---

## 六、接口与编程（单缓冲）

设端口地址 30CH，CS 与 WR1 由译码和 IOW 控制：

```asm
MOV DX, 30CH
MOV AL, 80H          ; 输出数字量 128
OUT DX, AL           ; 一次写操作完成转换
```

产生锯齿波：

```asm
MOV DX, 30CH
XOR AL, AL
LOOP1:
OUT DX, AL
INC AL
JMP LOOP1            ; 数字量循环变化 → 输出锯齿波
```

---

## 七、典型应用

- 波形发生器（锯齿波、三角波、正弦波查表）
- 电机调速、音量控制
- 模拟电压输出、程控电源

---

## 八、小结

- 8 位电流输出，双缓冲结构
- 单缓冲方式一次写操作即转换，最常用
- 输出电压与数字量成正比：Vout = −(D/256)Vref
- 配合循环/查表可生成任意波形
