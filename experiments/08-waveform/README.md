# 实验八：波形发生器（DAC0832 查表输出）

## 一、实验目的

1. 掌握 DAC0832 单缓冲方式的接口编程
2. 学会用查表法生成正弦波形
3. 理解采样点数与输出平滑度的关系

## 二、实验原理

预先在内存中建立 32 点正弦表（单极性，以 128 为中心、幅度 127）。CPU 依次把表中数据输出到 DAC，循环往复，输出端经运放得到连续正弦电压。用示波器可观察波形。

## 三、输出关系

```text
Vout = − (D / 256) × Vref
```

## 四、接线表

| 器件 | 连接 |
| :--- | :--- |
| DAC0832 D0~D7 | 数据总线 |
| CS/WR1 | 译码+写信号（30CH，单缓冲） |
| Iout1/Iout2 | 外接运算放大器 |
| 运放输出 | 示波器 |

## 五、实验步骤

1. 连接 DAC 与运放，输出接示波器
2. 运行程序，观察正弦波
3. 改变采样点数或在输出间加延时，观察频率与平滑度变化

## 六、思考与扩展

- 如何生成三角波、方波？（修改数据表或输出规律）
- 如何调节输出频率？（调整点间延时或表长）
