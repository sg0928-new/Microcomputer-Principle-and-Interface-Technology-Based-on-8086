# 逻辑运算与移位指令

---

## 一、逻辑运算指令

### 1. AND（与）

```text
AND DST, SRC       ; 按位相与，常用于屏蔽某些位（清零）
```

```asm
AND AL, 0FH        ; 保留低 4 位，高 4 位清零
```

### 2. OR（或）

```text
OR DST, SRC        ; 按位相或，常用于置位（合并）
```

```asm
OR AL, 80H         ; 最高位置 1，其余不变
```

### 3. XOR（异或）

```text
XOR DST, SRC       ; 按位异或，相同为 0、相异为 1
```

```asm
XOR AX, AX         ; 快速将 AX 清零（同时清 CF）
XOR AL, 01H        ; 翻转最低位
```

### 4. NOT（非）

```text
NOT OPR            ; 按位取反，不影响标志位
```

### 5. TEST（测试）

```text
TEST OPR1, OPR2    ; 执行 AND 但不保存结果，只影响标志位
```

常用于检测某一位是否为 1：

```asm
TEST AL, 80H       ; 测试最高位
JNZ  IS_ONE        ; 结果非 0（该位为 1）则跳转
```

> 逻辑运算指令会使 CF=OF=0，并按结果设置 ZF、SF、PF。

## 二、移位指令

移位次数为 1 时直接写 1；大于 1 时，次数必须放在 **CL** 中。

### 1. 算术/逻辑移位

| 指令 | 名称 | 动作 |
| :---: | :--- | :--- |
| SHL | 逻辑左移 | 各位左移，低位补 0，最高位进 CF |
| SAL | 算术左移 | 与 SHL 完全相同 |
| SHR | 逻辑右移 | 各位右移，高位补 0，最低位进 CF |
| SAR | 算术右移 | 各位右移，**高位补符号位**，最低位进 CF |

```text
SHL:                    SAR:
  ┌──────────────┐       ┌──────────────┐
CF│ b7 ... b1 b0│ 0   符号│ b7 ... b1 b0│→CF
  └──────────────┘       └──────────────┘
```

```asm
MOV AL, 02H
SHL AL, 1          ; AL=04H，相当于 ×2
MOV CL, 3
SHL AX, CL         ; AX 左移 3 位，相当于 ×8
```

**应用：** 左移 n 位相当于 ×2^n（无符号数快速乘法）；右移 n 位相当于 ÷2^n。

### 2. 循环移位

| 指令 | 名称 | 特点 |
| :---: | :--- | :--- |
| ROL | 循环左移 | 移出的最高位同时进 CF 和最低位 |
| ROR | 循环右移 | 移出的最低位同时进 CF 和最高位 |
| RCL | 带进位循环左移 | 把 CF 纳入循环一起移位 |
| RCR | 带进位循环右移 | 同上 |

```text
ROL:                RCL:
 ┌─────────────┐    ┌──────────────┐
 │  b7 ... b0  │◄┘  │CF b7 ... b0  │◄┘
 └──┬──────────┘    └──────────────┘
    └─► CF
```

---

## 三、典型应用

1. **位屏蔽/置位：** AND 清位、OR 置位、XOR 翻转
2. **快速乘除：** 用 SHL/SHR 替代乘除 2 的幂
3. **字/字节拼装：** 配合移位合并或拆分高、低字节
4. **位测试：** TEST + 条件跳转

---

## 四、小结

| 类别 | 指令 |
| :--- | :--- |
| 逻辑运算 | AND、OR、XOR、NOT、TEST |
| 移位 | SHL/SAL、SHR、SAR |
| 循环移位 | ROL、ROR、RCL、RCR |
| 多次移位 | 次数统一放入 CL |
