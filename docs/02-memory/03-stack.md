# 堆栈机制

## 一、堆栈的概念

堆栈是内存中一块特殊的存储区，按**后进先出（LIFO，Last In First Out）**规则存取数据，常用于：

- 保存断点地址（CALL、中断时自动保存返回地址）
- 保护现场（寄存器入栈/出栈）
- 子程序间传递参数
- 临时存储数据

堆栈由 `SS:SP` 定位，SP 始终指向**当前栈顶**。

---

## 二、堆栈的生长方向

8086 堆栈具有两个关键特性：

1. **向低地址方向生长**：压入数据时栈顶地址减小
2. **字操作**：每次 PUSH/POP 都以 16 位（一个字）为单位

```text
高地址  ┌──────────┐
        │ 已用数据  │
        │          │
SP ───► ├──────────┤  ← 栈顶（最后压入的数据）
        │  空闲    │
低地址  └──────────┘
```

---

## 三、PUSH 与 POP 的执行过程

### 1. PUSH（压栈）

```text
PUSH AX
```

执行步骤：

```text
① SP ← SP − 2          （栈顶先向低地址移动 2 字节）
② 将 AX 写入 SS:SP 处   （高字节在高地址，低字节在低地址）
```

### 2. POP（出栈）

```text
POP BX
```

执行步骤：

```text
① 从 SS:SP 处读取一个字 → BX
② SP ← SP + 2          （栈顶向高地址回退 2 字节）
```

> 记忆口诀：**压栈先改 SP 后存数，出栈先取数后改 SP。**

---

## 四、堆栈操作示例

```asm
MOV AX, 1234H
MOV BX, 5678H
PUSH AX          ; AX 入栈保存
PUSH BX          ; BX 入栈保存
POP  AX          ; 栈顶是 BX 的值 → AX = 5678H
POP  BX          ; BX = 1234H（两寄存器值被交换）
```

由于 LIFO 特性，连续 PUSH 后逆序 POP，可实现数据交换或现场恢复。

---

## 五、现场保护与恢复

子程序或中断处理中，常把用到的寄存器先入栈、结束时按相反顺序出栈：

```asm
PUSH AX          ; 保护现场
PUSH BX
; ... 处理逻辑 ...
POP  BX          ; 恢复时顺序相反
POP  AX
```

---

## 六、堆栈设置与注意事项

- 堆栈段在程序中定义，初始 SP 一般设为栈区大小（如 `DW 100 DUP(?)` 后 SP 指向栈底）
- PUSH 次数与 POP 次数必须匹配，否则栈失衡会导致返回地址错误
- SP 不能超出堆栈段范围，否则发生"堆栈溢出"
- 除 PUSH/POP 外，也可用 BP 作为基址访问栈中参数（`[BP+4]`、`[BP+6]`）

---

## 七、小结

| 要点 | 内容 |
| :--- | :--- |
| 存取规则 | 后进先出 LIFO |
| 定位 | SS:SP，SP 指向栈顶 |
| 生长方向 | 向低地址生长，字为单位 |
| PUSH | SP−2，再写数据 |
| POP | 先读数据，SP+2 |
| 用途 | 断点、现场保护、参数传递 |
