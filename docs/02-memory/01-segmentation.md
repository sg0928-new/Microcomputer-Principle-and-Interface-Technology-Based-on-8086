# 存储器分段管理

## 一、为什么要分段

8086 有 20 位地址总线，可寻址 1MB 内存（00000H ~ FFFFFH），但内部寄存器都是 16 位，只能表示 64KB（2^16）范围，无法直接提供 20 位地址。

为解决这个矛盾，8086 采用 **存储器分段（Segmentation）** 技术：

- 把 1MB 内存空间划分成若干个**逻辑段**
- 每个段最大 64KB，段内地址用 16 位寄存器即可表示
- 用"段地址 + 偏移地址"两个 16 位地址共同定位一个单元

---

## 二、段的划分规则

1. 每个段是一个可独立寻址的逻辑单位，分别存放代码、数据、堆栈等
2. 段的大小 ≤ 64KB（受 16 位偏移地址限制）
3. **段的起始地址必须能被 16 整除**（即物理地址最低 4 位为 0），称为"节（Paragraph）"边界
4. 段与段之间可以**相邻、重叠或部分重叠**，排列灵活

```text
1MB 空间
├─ 段1（代码段 CS） 起始地址 16 的倍数
├─ 段2（数据段 DS）
├─ 段3（堆栈段 SS）
└─ 段4（附加段 ES）
```

---

## 三、逻辑地址与物理地址

| 概念 | 形式 | 说明 |
| :--- | :--- | :--- |
| 逻辑地址 | 段地址 : 偏移地址 | 程序中使用的地址，如 `1234:0056H` |
| 物理地址 | 20 位实际地址 | 内存单元的真实编号，如 `12356H` |

- 段地址：段起始地址的高 16 位，存于段寄存器
- 偏移地址（Offset）：段内单元相对段首的距离，16 位

**同一个物理地址可对应多个不同的逻辑地址**，例如：

```text
1234:0056H → 12356H
1230:0056H → 12356H（段不同、偏移不同，结果相同）
```

---

## 四、四类段及其默认组合

| 段 | 段寄存器 | 存放内容 | 默认偏移寄存器 |
| :--- | :---: | :--- | :--- |
| 代码段 | CS | 程序指令 | IP |
| 数据段 | DS | 数据变量 | BX、SI、DI 等 |
| 堆栈段 | SS | 堆栈 | SP、BP |
| 附加段 | ES | 辅助数据 | DI（串操作） |

---

## 五、段的使用约定

- 取指令：默认使用 `CS:IP`
- 堆栈操作：默认使用 `SS:SP`
- 串操作源操作数：`DS:SI`；目的操作数：`ES:DI`
- 普通数据访问：默认 DS，也可用段超越前缀显式指定，如 `ES:[BX]`

---

## 六、小结

- 分段是为了用 16 位寄存器寻址 20 位（1MB）空间
- 段首地址必须 16 字节对齐，段最大 64KB
- 逻辑地址 = 段地址 : 偏移地址，物理地址由两者合成
- 4 个段寄存器 CS/DS/SS/ES 分别管理当前四类段
