# ADC0808/0809 模数转换器

ADC0808（0809）是 8 位、8 通道、逐次逼近型模数转换器，内置通道地址译码与三态输出锁存，可直接与 CPU 总线连接。

---

## 一、主要特性

- 8 位分辨率，8 路模拟输入（IN0~IN7）
- 逐次逼近（SAR）转换方式
- 三态输出锁存缓冲，便于挂接数据总线
- 单 +5V，参考电压 5V
- 28 引脚（0809 为 28 引脚）

---

## 二、内部结构

```text
IN0~IN7 ──► 8选1模拟开关 ──► 逐次逼近ADC ──► 三态锁存 ──► D0~D7
              ▲ ADDA/B/C
START 启动转换、ALE 锁存通道、EOC 转换结束、OE 输出允许
```

---

## 三、关键引脚

| 引脚 | 功能 |
| :--- | :--- |
| IN0~IN7 | 8 路模拟输入 |
| ADDA/B/C | 通道选择地址（C 为高位） |
| ALE | 地址锁存允许 |
| START | 启动转换（上升沿复位、下降沿开始） |
| EOC | 转换结束信号（转换中为低，结束变高） |
| OE | 输出允许，高电平时送出数字量 |
| D0~D7 | 数字量输出 |
| CLOCK | 时钟（典型 640kHz） |

### 通道选择

| C | B | A | 通道 |
| :---: | :---: | :---: | :--- |
| 0 | 0 | 0 | IN0 |
| 0 | 0 | 1 | IN1 |
| ... | ... | ... | ... |
| 1 | 1 | 1 | IN7 |

---

## 四、转换时序

1. 输出通道地址，ALE 有效锁存
2. 发 START 脉冲启动转换
3. 转换期间 EOC 变低（约 100μs）
4. 查询 EOC 或等待
5. EOC 变高后置 OE，读取数字量

---

## 五、数字量与输入电压关系

```text
D = (Vin / Vref) × 256
```

| 输入电压（Vref=5V） | 数字量 |
| :---: | :---: |
| 0V | 00H |
| 2.5V | 80H |
| 5V | FFH |

---

## 六、接口编程（查询方式）

设启动/通道端口 310H、读数据端口 311H，EOC 接某 PC 位：

```asm
; 选择通道 IN0 并启动
MOV DX, 310H
XOR AL, AL
OUT DX, AL              ; 写通道地址并启动

; 查询 EOC（此处略，实际接 PC 端口读取判断）
; ...

; 读取结果
MOV DX, 311H
IN  AL, DX              ; AL = 转换结果
```

实际硬件中常用三种方式获取转换结果：

| 方式 | 特点 |
| :--- | :--- |
| 查询 EOC | 简单可靠，最常用 |
| 延时等待 | 不接 EOC，等待固定转换时间 |
| 中断方式 | EOC 接 8259A，转换结束申请中断，CPU 效率高 |

---

## 七、典型应用

- 电压/温度/压力等模拟量采集
- 数据采集系统、万用表
- 传感器信号数字化后处理

---

## 八、小结

- 8 位 8 通道逐次逼近型，三态输出
- 流程：选通道→START 启动→等 EOC→OE 读数据
- 数字量与输入电压成正比
- 支持查询、延时、中断三种读取方式
