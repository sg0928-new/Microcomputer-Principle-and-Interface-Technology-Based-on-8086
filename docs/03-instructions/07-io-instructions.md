# I/O 端口指令

## 一、I/O 端口编址

8086 对外部设备采用**独立编址（隔离编址）**方式：

- I/O 端口与存储器分开，拥有独立的地址空间
- I/O 端口地址为 16 位，可寻址 64K 个 8 位端口（0000H~FFFFH）
- 实际常用 0~255（00H~FFH）端口
- 通过专用指令 IN/OUT 访问，控制信号 M/IO 为低电平

---

## 二、IN（输入指令）

从指定 I/O 端口读取数据到累加器。

### 1. 直接端口寻址（端口号 ≤ FFH）

```text
IN AL, PORT8       ; 字节：AL ← 端口 PORT8
IN AX, PORT8       ; 字：AX ← 连续两个端口
```

### 2. DX 间接端口寻址（端口号可 > FFH）

```text
MOV DX, PORT16
IN  AL, DX         ; AL ← DX 指向的端口
IN  AX, DX
```

---

## 三、OUT（输出指令）

把累加器数据写到指定 I/O 端口。

```asm
OUT 60H, AL        ; 直接输出字节到端口 60H
MOV DX, 300H
OUT DX, AX         ; 间接输出字
```

---

## 四、关键规则

1. I/O 指令**只能使用累加器 AL/AX 与端口交换数据**，不能用其他寄存器
2. 端口号 0~255 可用直接寻址；256~65535 必须先用 DX 存放
3. 字节传送用 AL，字传送用 AX
4. IN/OUT 不影响标志位

---

## 五、与接口芯片的关系

对 8255A、8253 等可编程接口芯片，正是通过 IN/OUT 完成：

- 向**控制寄存器端口**写控制字（OUT）
- 从**数据端口**读/写数据（IN/OUT）

```asm
; 向 8255A 控制口（假设端口 303H）写方式控制字
MOV DX, 303H
MOV AL, 80H
OUT DX, AL
```

---

## 六、小结

| 指令 | 功能 | 寻址方式 |
| :--- | :--- | :--- |
| IN AL/AX, PORT | 端口 → 累加器 | 直接（≤FFH）/ DX 间接 |
| OUT PORT, AL/AX | 累加器 → 端口 | 直接 / DX 间接 |

- 独立编址，专用 IN/OUT，数据经 AL/AX
- 是 CPU 与所有接口芯片通信的基础
