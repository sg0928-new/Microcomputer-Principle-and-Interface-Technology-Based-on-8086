# 8255A 可编程并行接口

8255A（PPI，Programmable Peripheral Interface）是最常用的可编程并行 I/O 接口，提供三个 8 位端口，可灵活配置工作方式。

---

## 一、主要特性

- 3 个 8 位端口：PA、PB、PC，共 24 条 I/O 线
- 3 种工作方式：方式 0、方式 1、方式 2
- PC 可分为高 4 位（PC7~PC4）和低 4 位（PC3~PC0）
- 单一 +5V，40 引脚

---

## 二、内部结构与端口

```text
          ┌──────────────┐
PA0~PA7 ──► A 组（PA + PC高4位）│
PB0~PB7 ──► B 组（PB + PC低4位）│
PC0~PC7 ──►             │
          └──────────────┘
```

### 端口选择（A1、A0）

| A1 | A0 | 选择端口 |
| :---: | :---: | :--- |
| 0 | 0 | PA |
| 0 | 1 | PB |
| 1 | 0 | PC |
| 1 | 1 | 控制寄存器 |

---

## 三、三种工作方式

### 方式 0：基本输入/输出

- 无条件传送，无需握手信号
- PA、PB、PC 高/低 4 位可分别设置输入或输出
- 适用于 LED、开关等简单外设

### 方式 1：选通输入/输出

- 带握手（选通）信号的并行传送
- PC 中部分引脚自动作为 STB、IBF、INTR 等联络信号
- 适用于需要应答的设备（如打印机、键盘）

### 方式 2：双向传送

- 仅 PA 支持，双向 8 位数据总线
- 占用 PC 5 根线作联络
- 适用于既要输入又要输出的场合

---

## 四、方式控制字

### 1. 方式选择控制字（D7 = 1）

```text
 D7  D6 D5  D4  D3  D2  D1  D0
 ┌──┬─────┬──┬──┬──┬──┬──┐
 │1 │A组方式│PA│PC高│B方式│PB│PC低│
 └──┴─────┴──┴──┴──┴──┴──┘
```

- D7：固定为 1（标识方式控制字）
- D6D5：A 组方式（00=方式0，01=方式1，1x=方式2）
- D4：PA 方向（1=输入，0=输出）
- D3：PC 高 4 位方向
- D2：B 组方式（0=方式0，1=方式1）
- D1：PB 方向
- D0：PC 低 4 位方向

### 2. C 口置位/复位控制字（D7 = 0）

```text
 D7  D6 D5 D4  D3 D2 D1  D0
 ┌──┬────────┬───────┬──┐
 │0 │  无关   │ 位选择 │  │← 1置位/0复位
 └──┴────────┴───────┴──┘
```

D3D2D1 选择 PC 的哪一位（000=PC0 … 111=PC7）。

---

## 五、编程示例

设端口地址为 300H~303H，PA 方式 0 输出、PB 方式 0 输入：

```asm
; 控制字：10000010B = 82H
MOV DX, 303H
MOV AL, 82H
OUT DX, AL

; PA 输出数据
MOV DX, 300H
MOV AL, 0FFH
OUT DX, AL

; 读取 PB
MOV DX, 301H
IN  AL, DX
```

C 口 PC0 置 1：

```asm
MOV DX, 303H
MOV AL, 01H
OUT DX, AL
```

---

## 六、典型应用

| 应用 | 端口配置 |
| :--- | :--- |
| LED/数码管输出 | PA 方式 0 输出 |
| 开关/按键输入 | PB 方式 0 输入 |
| 打印机接口 | PA 方式 1 输出 |
| 键盘扫描 | 行列信号 + PC 联络 |

---

## 七、小结

- 3 个端口 PA/PB/PC，24 条 I/O 线
- 方式 0 基本 IO、方式 1 选通、方式 2 双向（仅 PA）
- 方式控制字 D7=1；C 口置位/复位字 D7=0
- 控制字写入控制寄存器（A1A0=11）
