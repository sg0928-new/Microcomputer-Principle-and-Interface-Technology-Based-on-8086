# 8253/8254 可编程定时器/计数器

8253（PIT，Programmable Interval Timer）内含 3 个独立的 16 位计数器，可实现定时、计数、产生方波等功能。8254 是其增强型（计数频率更高，兼容 8253）。

---

## 一、主要特性

- 3 个独立 16 位计数器：计数器 0、1、2
- 每个计数器有：CLK（时钟输入）、GATE（门控）、OUT（输出）
- 6 种工作方式（方式 0~5）
- 二进制或 BCD 计数，最高 16 位
- 单一 +5V，24 引脚

---

## 二、内部结构

```text
计数器0：CLK0 GATE0 OUT0
计数器1：CLK1 GATE1 OUT1
计数器2：CLK2 GATE2 OUT2
数据总线缓冲器、读写逻辑、控制字寄存器
```

### 端口选择（A1、A0）

| A1 | A0 | 选择 |
| :---: | :---: | :--- |
| 0 | 0 | 计数器 0 |
| 0 | 1 | 计数器 1 |
| 1 | 0 | 计数器 2 |
| 1 | 1 | 控制字寄存器 |

---

## 三、控制字格式

```text
 D7 D6  D5 D4  D3 D2 D1  D0
┌─────┬─────┬───────┬──┐
│SC选择 │ RL读写 │ M方式  │BCD│
└─────┴─────┴───────┴──┘
```

- SC（D7D6）：选择计数器（00/01/10，11 非法）
- RL（D5D4）：读写格式
  - 00：锁存命令
  - 01：只读/写低字节
  - 10：只读/写高字节
  - 11：先低字节、后高字节
- M（D3D2D1）：工作方式选择
- D0：0=二进制，1=BCD

---

## 四、六种工作方式

| 方式 | 名称 | OUT 输出特点 |
| :---: | :--- | :--- |
| 0 | 计数结束中断 | 写入初值后 OUT 变低，计数到 0 变高 |
| 1 | 可重触发单稳态 | GATE 触发，输出一个宽度可控的单脉冲 |
| 2 | 速率发生器 | 周期性负脉冲，周期=初值×CLK |
| 3 | 方波发生器 | 输出连续方波（常用） |
| 4 | 软件触发选通 | 计数到 0 输出一个时钟宽负脉冲 |
| 5 | 硬件触发选通 | GATE 上升沿触发计数 |

### 方式 3 方波发生器（重点）

- 初值 N 为偶数：高低电平各 N/2
- 周期性输出方波，常用于驱动扬声器、波特率时钟

---

## 五、计数初值计算

```text
计数初值 N = 输入时钟频率 fCLK ÷ 期望输出频率 fOUT
```

例：CLK 输入 1MHz，要产生 1kHz 方波：

```text
N = 1,000,000 ÷ 1,000 = 1000 = 03E8H
```

---

## 六、编程示例

端口地址 304H~307H，计数器 0 工作方式 3，初值 1000：

```asm
; 控制字：00 11 011 0 = 36H
MOV DX, 307H
MOV AL, 36H
OUT DX, AL

; 写计数器 0 初值（先低后高）
MOV DX, 304H
MOV AX, 1000
OUT DX, AL          ; 低字节
MOV AL, AH
OUT DX, AL          ; 高字节
```

读取当前计数值（先锁存再读）：

```asm
MOV DX, 307H
MOV AL, 00H
OUT DX, AL          ; 锁存计数器 0
MOV DX, 304H
IN  AL, DX
MOV BL, AL
IN  AL, DX
MOV BH, AL          ; BX = 当前计数值
```

---

## 七、PC 机中的 8253

端口 40H~43H：

- 计数器 0：系统日时钟（约 18.2 次/秒中断）
- 计数器 1：DRAM 刷新定时
- 计数器 2：驱动扬声器发声（端口 61H 控制）

---

## 八、小结

- 3 个独立 16 位计数器，CLK/GATE/OUT
- 方式 2 速率发生器、方式 3 方波最常用
- 初值 N = fCLK ÷ fOUT
- 16 位初值先写低字节、后写高字节
