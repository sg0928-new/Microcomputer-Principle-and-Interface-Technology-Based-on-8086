# 8237 DMA 控制器

8237（DMAC，DMA Controller）用于在**不经过 CPU** 的情况下，直接在 I/O 设备与存储器之间（或存储器之间）高速传送数据。

---

## 一、为什么需要 DMA

用 CPU 执行 IN/OUT 传送数据，每条指令都要取指、译码，速度受限。对于磁盘、高速 ADC 等需要批量快速传送的设备：

- DMA 方式由专门控制器接管总线，数据直接在设备与内存间流动
- 传送期间 CPU 释放总线（进入保持状态）
- 大幅提高数据吞吐量，减轻 CPU 负担

---

## 二、主要特性

- 4 个独立通道（CH0~CH3），每通道可寻址一个设备
- 每通道 16 位地址寄存器、16 位字节计数寄存器（一次最多 64KB）
- 3 种基本传送方式：单字节、块（连续）、请求（按需）
- 支持存储器到存储器传送
- 可级联扩展更多通道
- 单一 +5V，40 引脚

---

## 三、内部结构

```text
4 个通道：每个含 基址/当前地址寄存器、基字/当前字节计数寄存器
公共寄存器：方式寄存器、命令寄存器、状态寄存器、
            先/后触发器、屏蔽寄存器、临时寄存器
时序与控制逻辑、优先级编码逻辑
```

---

## 四、关键引脚

| 引脚 | 功能 |
| :--- | :--- |
| DREQ0~DREQ3 | 设备 DMA 请求输入 |
| DACK0~DACK3 | 控制器对设备的应答 |
| HRQ | 向 CPU 发总线请求（接 HOLD） |
| HLDA | CPU 总线响应（接 HLDA） |
| MEMR/MEMW | 存储器读/写 |
| IOR/IOW | I/O 读/写 |
| ADSTB/AEN | 地址选通/允许（高 8 位地址） |
| EOP | 传送结束信号 |

---

## 五、DMA 传送过程

1. 设备向 8237 发 DREQ
2. 8237 向 CPU 发 HRQ 请求总线
3. CPU 在当前总线周期结束后释放总线，回 HLDA
4. 8237 输出内存地址，发 MEMR/IOW 等控制信号，直接传送一个字节
5. 地址寄存器 +1、字节计数 −1
6. 重复直到计数到 0，EOP 有效，总线交还 CPU

---

## 六、方式寄存器

| 位 | 含义 |
| :--- | :--- |
| D1D0 | 通道选择 |
| D3D2 | 传送方式（校验/写/读） |
| D4 | 自动预置允许 |
| D5 | 地址递增/递减 |
| D7D6 | 方式（请求/单字节/块/级联） |

---

## 七、编程步骤

1. 发主清除命令（软件复位）
2. 写入通道 16 位内存地址（先低字节、后高字节）
3. 写入传送字节数（实际计数 N−1）
4. 写入方式寄存器
5. 清除屏蔽、写入命令寄存器，启动通道

```asm
; 通道0，端口 00H~0FH（PC 标准地址）
; 写地址（先/后触发器自动翻转）
MOV AL, 00H
OUT 00H, AL        ; 低 8 位地址
MOV AL, 10H
OUT 00H, AL        ; 高 8 位地址
; 写字节计数
MOV AL, 0FFH
OUT 01H, AL
MOV AL, 00H
OUT 01H, AL
; 清屏蔽启动
MOV AL, 00H
OUT 0AH, AL
```

---

## 八、PC 机中的 8237

- 通道 0：DRAM 刷新（早期 PC）
- 通道 1：保留/用户
- 通道 2：软盘
- 通道 3：硬盘
- 页面寄存器（74LS670）配合提供高 4 位地址，构成 20 位系统地址

---

## 九、DMA 与中断方式对比

| 对比项 | 中断方式 | DMA 方式 |
| :--- | :--- | :--- |
| 数据通路 | 经 CPU 寄存器中转 | 设备与内存直接传送 |
| CPU 参与 | 执行中断服务程序 | 仅让出总线，不参与 |
| 响应时机 | 指令执行完 | 总线周期结束即可 |
| 速度 | 较慢 | 高 |
| 适用 | 中低速、事件处理 | 高速批量数据 |

---

## 十、小结

- 8237 提供 4 通道、高速直接存储器访问
- 传送时 CPU 释放总线，硬件自动完成地址递增与计数
- 编程：复位→写地址→写计数→写方式→清屏蔽启动
- 适合磁盘、高速采集等大批量数据场景
