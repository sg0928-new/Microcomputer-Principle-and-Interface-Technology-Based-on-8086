# Proteus 8086 硬件仿真搭建指南

本指南说明如何在 Proteus（ISIS）中搭建 8086 最小系统、接入接口芯片并加载汇编程序，配合 `experiments/` 下的实验代码完成硬件仿真。

> Proteus 工程文件（.pdsprj）为专有二进制格式，无法以文本形式提供，需按本指南在 Proteus 中手动搭建。

## 二、搭建 8086 最小系统

### 1. 时钟与复位

- 8284 的 `CLK` 输出接 8086 的 `CLK`
- 8284 `RES` 接 8086 `RESET`
- 8284 晶振输入接石英晶振或直接用数字时钟源

### 2. 地址锁存（解决分时复用）

- 8086 `AD0~AD15` 接 2 片 74LS373 输入，`ALE` 接锁存器使能端
- 锁存输出得到稳定的 `A0~A15`
- 高 4 位 `A16~A19` 再用 1 片 74LS373 锁存

### 3. 数据收发

- 8086 `AD0~AD15` 经 74LS245 形成独立 16 位数据总线 `D0~D15`
- 收发方向由 `DEN/DT-R` 或 RD/WR 逻辑控制

### 4. 工作模式

- 最小模式：`MN/MX` 接高电平（+5V），控制信号由 8086 直接产生

## 三、地址译码与端口分配

74LS138 对高位地址译码，产生各芯片片选。推荐统一端口规划：

| 芯片 | 端口 | 地址范围 |
| :--- | :--- | :--- |
| 8255A | PA/PB/PC/CR | 300H~303H |
| 8253 | CT0/CT1/CT2/CR | 304H~307H |
| 8251A | 数据/控制 | 308H~309H |
| DAC0832 | 数据 | 30CH |
| ADC0808 | 启动/数据 | 310H~311H |
| 8259A | 偶/奇地址 | 20H~21H |

### 译码思路

- 把 A9~A4 作为 138 的输入/使能，使能条件对应地址 `300H` 段
- 138 的 Y0、Y1、Y2… 分别接 8255、8253 等的 CS
- 芯片内部 A0/A1 接系统地址总线最低两位

## 四、加载汇编程序

1. 在 DOSBox/VSCode 中用 MASM 汇编链接，或用工具导出为 `.hex` / `.bin`
2. 双击 Proteus 中的 8086 芯片，打开属性
3. 在 `Program File` 一栏选择生成的 hex/bin 文件
4. 设置 `Internal Memory Size`（按需，如 0x10000）
5. 确认时钟频率与 8284 一致

---

## 五、仿真运行

1. 点击左下角运行按钮开始仿真
2. 观察 LED、数码管、扬声器等外设动作
3. 用示波器/逻辑分析仪观察总线时序与波形
4. 暂停后可查看引脚电平，定位接线问题

---

## 六、常见问题排查

| 现象 | 可能原因 |
| :--- | :--- |
| 程序无反应 | Program File 未加载或路径错误；复位/时钟未接 |
| 外设不动作 | CS 译码错误、端口地址与代码不一致 |
| 数据乱跳 | 地址未正确锁存、245 方向错误 |
| 定时频率不对 | 8253 初值与 CLK 频率不匹配 |
| 中断不触发 | 8259 屏蔽位未清除、IF 未置 1、未发 EOI |

---

## 七、推荐学习顺序

1. 先搭最小系统，跑通 `experiments/01-led-flow`
2. 加入 8255，完成数码管、键盘实验
3. 加入 8253、8259，完成定时与中断
4. 最后接入 ADC/DAC，完成采集与波形综合实验
