# 实验二：交通信号灯控制（8255A）

## 一、实验目的

1. 掌握多状态顺序控制的程序设计方法
2. 进一步熟悉 8255A 方式 0 输出
3. 理解交通灯各相位的时序配合

## 二、实验原理

用 PA 口 6 个输出位分别控制两个方向（A、B）的红、黄、绿灯。程序按四个相位循环输出不同的灯态组合，每个相位维持一段时间，模拟真实交通灯工作逻辑。

## 三、灯位定义

| PA 位 | 灯 |
| :---: | :--- |
| PA0 | B 方向红灯 |
| PA1 | B 方向黄灯 |
| PA2 | B 方向绿灯 |
| PA3 | A 方向红灯 |
| PA4 | A 方向黄灯 |
| PA5 | A 方向绿灯 |

## 四、相位与输出数据

| 相位 | 状态 | 输出值 |
| :---: | :--- | :---: |
| 1 | A 绿、B 红 | 11H |
| 2 | A 黄、B 红 | 09H |
| 3 | A 红、B 绿 | 22H |
| 4 | A 红、B 黄 | 24H |

## 五、接线表

| 8255A | 连接 |
| :--- | :--- |
| PA0~PA5 | 经电阻接 6 个 LED（两方向红黄绿灯） |
| CS | 译码输出（300H~303H） |
| RD/WR/A0/A1 | 对应接 8086 总线 |

## 六、实验步骤

1. 连接电路并加载程序
2. 运行，观察两方向信号灯按相位循环切换
3. 调整长、短延时，使绿灯时间明显长于黄灯闪烁时间

## 七、思考与扩展

- 如何加入夜间黄灯闪烁模式？（仅输出黄灯位并快速循环）
- 结合 8253 硬件定时替代软件延时，提高定时精度（见实验五思路）
