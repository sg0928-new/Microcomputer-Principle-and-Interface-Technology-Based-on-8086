# 实验三：数码管动态显示（8255A）

## 一、实验目的

1. 理解七段数码管的段码编码原理
2. 掌握动态扫描显示的工作机制
3. 学会用查表指令 XLAT/查表法获取段码

## 二、实验原理

4 位共阴极数码管的段选线并联接 PA，位选线接 PB。动态扫描利用人眼视觉暂留：CPU 依次选通每一位并送出对应段码，快速循环切换，看起来 4 位同时稳定显示。

## 三、共阴极段码表（a~g, dp）

| 数字 | 段码 | 数字 | 段码 |
| :---: | :---: | :---: | :---: |
| 0 | 3FH | 5 | 6DH |
| 1 | 06H | 6 | 7DH |
| 2 | 5BH | 7 | 07H |
| 3 | 4FH | 8 | 7FH |
| 4 | 66H | 9 | 6FH |

> 共阳极段码为共阴极段码按位取反。

## 四、接线表

| 8255A | 连接 |
| :--- | :--- |
| PA0~PA7 | 数码管 a~dp 段脚（经限流电阻） |
| PB0~PB3 | 4 位数码管公共端（经驱动管） |
| CS | 译码输出 300H~303H |

## 五、实验步骤

1. 连接段选、位选电路
2. 加载程序运行，观察 4 位显示 `1234`
3. 修改 DISP 数组，显示自定义数字
4. 调整扫描延时，体会闪烁与亮度的关系

## 六、思考与扩展

- 如何显示字母 A~F？（扩展段码表）
