# 实验四：矩阵键盘抢答器（8255A）

## 一、实验目的

1. 掌握矩阵键盘的行列扫描原理
2. 学会按键检测与去抖处理
3. 理解抢答锁定的程序逻辑

## 二、实验原理

4×4 矩阵键盘的 4 根行线接 PA（输出），4 根列线接 PC（输入）。扫描时逐行输出低电平，再读取列线：若某列也为低，说明该行列交叉处按键按下。程序检测到第一个按键即锁定其编号，实现"先按者有效"的抢答逻辑，等待按键释放后再进入下一轮。

## 三、控制字

PA 方式 0 输出、PC 方式 0 输入：

```text
D7=1 D6D5=00 D4=0(PA输出) D3=1(PC高4位输入)
D2=0 D1=0 D0=0
控制字 = 10001000B = 88H
```

## 四、键号计算

```text
键号 = 行号 × 4 + 列号
```

## 五、接线表

| 8255A | 连接 |
| :--- | :--- |
| PA0~PA3 | 键盘 4 行 |
| PC0~PC3 | 键盘 4 列（接上拉电阻） |
| 按键交叉点 | 行、列之间接按键开关 |

## 六、实验步骤

1. 连接矩阵键盘与上拉电阻
2. 加载程序运行，按下不同按键，观察 PB 输出的行/列编码
3. 验证多键同时按下时，只锁定最先扫描到的键
