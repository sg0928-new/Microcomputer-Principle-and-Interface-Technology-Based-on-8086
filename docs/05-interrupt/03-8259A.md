# 8259A 可编程中断控制器

8259A（PIC，Programmable Interrupt Controller）用于管理多个外部可屏蔽中断，进行优先级仲裁并向 CPU 提供中断类型号。

---

## 一、主要功能

- 管理 **8 级**中断请求（IR0~IR7）
- 通过级联最多扩展到 **64 级**（1 主 + 8 从）
- 可编程设置优先级方式、中断屏蔽、中断类型号基值
- 中断响应时自动向 CPU 提供当前中断的类型号

---

## 二、内部结构

```text
IR0~IR7 ──► 中断请求寄存器 IRR（锁存请求）
                 │
          优先级裁决器 PR（比较优先级）
                 │
          中断服务寄存器 ISR（记录正在处理的中断）
                 │
             INT ──► CPU
数据总线缓冲器、读写逻辑、级联缓冲比较器
```

| 寄存器 | 作用 |
| :--- | :--- |
| IRR | 保存所有未被响应的中断请求 |
| ISR | 保存正在被服务的中断 |
| IMR | 中断屏蔽寄存器，逐位屏蔽 IR |
| PR | 判别优先级，选出最高者 |

---

## 三、引脚与端口

- IR0~IR7：8 个中断请求输入
- INT：向 CPU 发中断请求
- INTA：接收 CPU 中断响应
- CAS0~CAS2：级联线
- 内部两个端口：A0=0 为偶地址，A0=1 为奇地址
- PC 中主片端口 20H/21H，从片 0A0H/0A1H

---

## 四、初始化命令字 ICW

初始化时按顺序写入 ICW1~ICW4（部分可省略）。

### ICW1（偶地址）

设置触发方式、是否级联、是否需要 ICW4。

### ICW2（奇地址）

设置**中断类型号基值**：高 5 位由用户设定，低 3 位对应 IR 编号自动填入。

> PC 中基值为 08H，故 IR0~IR7 对应类型号 08H~0FH。

### ICW3（奇地址）

标识主/从片级联连接关系。

### ICW4（奇地址）

设置全嵌套/特殊全嵌套、缓冲方式、自动 EOI、CPU 类型（8086）。

---

## 五、操作命令字 OCW（运行期）

| 命令字 | 功能 |
| :--- | :--- |
| OCW1 | 设置/读取中断屏蔽寄存器 IMR |
| OCW2 | 设置优先级循环、发 EOI（结束中断命令） |
| OCW3 | 设置特殊屏蔽、读取 IRR/ISR |

### EOI 中断结束命令

普通 EOI 命令字 `20H`：

```asm
MOV AL, 20H
OUT 20H, AL        ; 服务结束，清除 ISR 对应位
```

### 屏蔽操作

```asm
IN  AL, 21H        ; 读 IMR
OR  AL, 01H        ; 屏蔽 IR0
OUT 21H, AL
```

---

## 六、优先级管理方式

| 方式 | 说明 |
| :--- | :--- |
| 全嵌套方式（默认） | IR0 最高、IR7 最低，固定优先级 |
| 自动循环 | 刚服务完的中断优先级变为最低 |
| 特殊循环 | 用程序指定最低优先级 |
| 特殊屏蔽 | 动态改变优先级结构 |

---

## 七、PC 兼容机中的 8259A

| 项目 | 主片 | 从片 |
| :--- | :--- | :--- |
| 端口 | 20H/21H | A0H/A1H |
| 类型号 | 08H~0FH | 70H~77H |
| 级联 | 从片接主片 IR2 | — |

---

## 八、小结

- 8259A 管理 8 级中断，级联可扩 64 级
- 初始化用 ICW1~ICW4，运行期用 OCW1~OCW3
- ICW2 决定类型号基值，OCW2 发 EOI
- 默认全嵌套，IR0 优先级最高
