# 总线时序与时序概念

## 一、基本时序单位

| 概念 | 含义 |
| :--- | :--- |
| 时钟周期（T 状态） | CPU 动作的最小时间单位，等于 CLK 周期，5MHz 时为 200ns |
| 总线周期 | CPU 通过总线完成一次内存或 I/O 访问所需的时间，通常含 4 个 T 状态（T1~T4） |
| 指令周期 | 执行一条指令所需的时间，由若干总线周期组成 |

三者关系：

```text
时钟周期 ⊂ 总线周期（4 个 T）⊂ 指令周期（若干总线周期）
```

---

## 二、典型总线周期（4 个 T 状态）

### 1. 存储器读周期

```text
T1：输出 20 位地址，ALE 有效锁存地址；BHE 有效
T2：地址撤销，AD 线浮空，RD 有效，准备读数据
T3：存储器把数据送到数据总线；采样 READY
T4：CPU 采样数据总线读取数据，RD 撤销，周期结束
```

### 2. 存储器写周期

```text
T1：输出地址并锁存，BHE 有效
T2：CPU 把待写数据送上数据总线，WR 有效
T3：数据保持，写入存储器；采样 READY
T4：WR 撤销，结束写周期
```

### 3. I/O 读写周期

- 与内存读写类似，但 M/IO 为低电平
- I/O 端口只使用 16 位地址（A0~A15）
- 8086 的 I/O 周期在 T3 前自动插入一个空闲状态，时序稍长

---

## 三、等待周期 Tw（READY 机制）

当内存或外设速度较慢，无法在 T3 前准备好数据时：

1. 设备在 T3 之前使 `READY = 0`（经 8284 同步）
2. CPU 在 T3 上升沿检测到 READY 无效，就在 **T3 与 T4 之间插入等待周期 Tw**
3. 每个 Tw 继续采样 READY，直到 READY 变高，才进入 T4 完成访问

```text
T1 ── T2 ── T3 ── Tw ── Tw ── T4
                  ▲ READY=0 持续等待
```

**意义：** 让高速 CPU 能与低速存储器/外设协调工作，是硬件时序配合的核心机制。

---

## 四、空闲周期 Ti

当 CPU 短期内不需要访问总线（EU 内部运算耗时较长）时，BIU 不执行总线周期，总线进入空闲状态，产生空闲周期 Ti。此时：

- 地址/数据复用线上保持上一周期状态或浮空
- 指令队列继续为 EU 提供指令
- 一旦有新的访问需求，立即进入新的总线周期

---

## 五、复位与启动时序

RESET 引脚保持高电平至少 4 个时钟周期即可复位：

- 内部寄存器被初始化：`CS = FFFFH`，`IP = 0000H`，其余寄存器与队列清零
- 复位后第一条指令地址：

```text
CS:IP = FFFF:0000 → 物理地址 FFFF0H
```

- 该单元通常存放一条**无条件跳转指令**，跳到系统主程序入口（BIOS 引导原理）

---

## 六、小结

| 时序概念 | 要点 |
| :--- | :--- |
| 时钟周期 | 最小时间单位 T |
| 总线周期 | 一次访存/IO，基本 4 个 T（T1~T4） |
| Tw | READY 无效时插入，等待慢速设备 |
| Ti | 无总线访问时的空闲周期 |
| 复位 | 从 FFFF0H 取第一条指令 |
