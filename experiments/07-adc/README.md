# 实验七：电压采集（ADC0808 + 8255A）

## 一、实验目的

1. 掌握 ADC0808 的启动、等待与读取流程
2. 理解模拟量到数字量的转换关系
3. 学会用延时/查询方式配合转换时序

## 二、实验原理

CPU 向启动端口写通道号并启动转换，等待约 100μs 转换完成后，从数据端口读取 8 位数字量，并把结果送到 8255 PA 驱动 LED 光柱，直观反映输入电压大小。

## 三、数字量与电压

```text
D = (Vin / Vref) × 256
```

## 四、接线表

| 器件 | 连接 |
| :--- | :--- |
| ADC0808 IN0 | 电位器/模拟输入 |
| START/ALE | 译码+写信号（310H） |
| OE | 译码+读信号（311H） |
| D0~D7 | 数据总线 |
| 8255 PA | LED 光柱 |

## 五、实验步骤

1. 用电位器调节 IN0 输入电压
2. 运行程序，观察 LED 光柱随电压变化
3. 若连接了 EOC，可改为查询 EOC 或中断方式读取

## 六、思考与扩展

- 如何循环采集 8 个通道的数据？（通道地址 0~7 循环写）
- 如何把采集值换算成实际电压并在数码管显示？
