# 引脚功能与工作模式

8086 采用 40 引脚 DIP 封装，引脚可分为四类：地址/数据总线、地址/状态总线、控制总线、电源与时钟。由于引脚数量有限，部分引脚采用**分时复用**。

---

## 一、引脚分类总览

### 1. 地址/数据复用线（16 根）

| 引脚 | 功能 |
| :--- | :--- |
| AD0 ~ AD15 | 低 16 位地址/数据分时复用：先传低 16 位地址，再传 16 位数据 |

### 2. 地址/状态复用线（4 根）

| 引脚 | 功能 |
| :--- | :--- |
| A19/S6 ~ A16/S3 | 高 4 位地址与状态信息分时复用 |

- S6：恒为 0，表示 8086 当前占用总线
- S5：指示 IF 标志状态
- S4、S3：组合表示当前使用的段寄存器（00=ES，01=SS，10=CS，11=DS）

### 3. 主要控制引脚

| 引脚 | 名称 | 方向 | 功能 |
| :--- | :--- | :---: | :--- |
| MN/MX | 最小/最大模式选择 | 输入 | 接 +5V 为最小模式，接地为最大模式 |
| RD | 读信号 | 输出 | 有效时表示 CPU 正在读内存或 I/O |
| READY | 准备就绪 | 输入 | 低电平时插入等待周期 Tw，用于慢速设备 |
| INTR | 可屏蔽中断请求 | 输入 | 受 IF 控制 |
| NMI | 非屏蔽中断请求 | 输入 | 不受 IF 控制，上升沿触发 |
| RESET | 复位 | 输入 | 高电平复位，CPU 从 FFFF0H 开始执行 |
| CLK | 时钟 | 输入 | 由 8284 时钟发生器提供 |
| TEST | 测试 | 输入 | 配合 WAIT 指令，低电平有效 |
| BHE/S7 | 高字节允许 | 输出 | BHE=0 时启用高 8 位数据总线 |
| ALE | 地址锁存允许 | 输出 | 下降沿锁存复用线上的地址（最小模式） |
| M/IO | 存储器/IO 选择 | 输出 | 高电平访问内存，低电平访问 I/O |
| WR | 写信号 | 输出 | 有效时表示 CPU 正在写内存或 I/O |
| INTA | 中断响应 | 输出 | 响应可屏蔽中断时输出 |
| HOLD/HLDA | 总线请求/响应 | 双向 | 用于 DMA 等设备请求总线 |

> 注意区分：8086 是 `M/IO`（高电平选内存），8088 是 `IO/M`（逻辑相反）。

---

## 二、最小模式（Minimum Mode）

当 `MN/MX = 1`（接高电平）时，系统只有一个 8086，所有总线控制信号由 8086 直接产生。

**特点：**

- 系统结构简单，所需芯片少
- 需外接：1 片 8284（时钟发生器）、3 片 74LS373（地址锁存器）、2 片 74LS245（数据收发器）
- 8086 直接产生 ALE、RD、WR、M/IO、INTA 等控制信号
- 适合小型单处理器系统

```text
              ┌─────────┐
   CLK ──────►│         │
              │  8086   │◄──── AD0~AD15 ────► 74LS245 ──► 数据总线
   READY ────►│         │◄──── A0~A19  ────► 74LS373 ──► 地址总线
              └─────────┘
                  ▲ 8284 提供 CLK/READY
```

---

## 三、最大模式（Maximum Mode）

当 `MN/MX = 0`（接地）时，系统可含多个处理器（如配合 8087 数值协处理器、8089 I/O 处理器），总线控制信号改由 **8288 总线控制器**译码产生。

**特点：**

- 8086 的 S0、S1、S2 三个状态引脚输出总线周期编码
- 8288 对 S0~S2 译码，产生 ALE、MRDC、MWTC、IORC、IOWC、INTA 等信号
- 支持多处理器协同，系统功能强、结构复杂
- 增加总线仲裁逻辑（8289 仲裁器）

### S0、S1、S2 状态编码

| S2 | S1 | S0 | 总线周期 |
| :---: | :---: | :---: | :--- |
| 0 | 0 | 0 | 中断响应 |
| 0 | 0 | 1 | 读 I/O |
| 0 | 1 | 0 | 写 I/O |
| 0 | 1 | 1 | 暂停（HLT） |
| 1 | 0 | 0 | 取指令 |
| 1 | 0 | 1 | 读内存 |
| 1 | 1 | 0 | 写内存 |
| 1 | 1 | 1 | 无源（无总线周期） |

---

## 四、两种模式对比

| 对比项 | 最小模式 | 最大模式 |
| :--- | :--- | :--- |
| MN/MX | 接高电平（1） | 接地（0） |
| 控制信号产生 | 8086 直接产生 | 8288 总线控制器译码产生 |
| 处理器数量 | 单处理器 | 可多处理器（8087/8089） |
| 典型芯片 | 8284、74LS373、74LS245 | 增加 8288、8289 |
| 适用场景 | 小型系统 | 中大型复杂系统 |

---

## 五、小结

- 40 引脚中 AD0~AD15、A16~A19 为分时复用，需用 ALE 锁存地址
- 由 MN/MX 决定最小/最大两种工作模式
- 最小模式结构简单、信号直接；最大模式经 8288 译码、支持多处理器
