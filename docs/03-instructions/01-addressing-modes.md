# 寻址方式

寻址方式指**寻找指令中操作数所在地址的方法**。8086 的寻址方式分为两大类：数据寻址（本文件重点）与转移地址寻址。

---

## 一、立即寻址（Immediate）

操作数直接写在指令中，作为指令的一部分，常用于给寄存器赋初值。

```asm
MOV AX, 1234H      ; AX ← 1234H
MOV BL, 20H        ; BL ← 20H
```

- 立即数只能作为**源操作数**，不能作为目的
- 速度快，但数值固定不灵活

---

## 二、寄存器寻址（Register）

操作数在 CPU 寄存器中，不需访问内存，执行速度快。

```asm
MOV AX, BX         ; AX ← BX
ADD CX, DX         ; CX ← CX + DX
```

---

## 三、存储器寻址（操作数在内存中）

有效地址 EA（偏移地址）由以下分量组合：`基址(BX/BP) + 变址(SI/DI) + 位移量`。

### 1. 直接寻址（Direct）

偏移地址直接写在指令中，默认段为 DS。

```asm
MOV AX, [2000H]    ; AX ← DS:2000H 处的一个字
MOV AL, [1000H]    ; AL ← DS:1000H 处的一个字节
```

符号变量形式：

```asm
MOV AX, VALUE      ; VALUE 为变量名
```

### 2. 寄存器间接寻址（Register Indirect）

偏移地址放在 BX、BP、SI、DI 中，寄存器用方括号括起。

```asm
MOV AX, [BX]       ; 默认段 DS
MOV AX, [SI]       ; 默认段 DS
MOV AX, [DI]       ; 默认段 DS
MOV AX, [BP]       ; 默认段 SS（BP 例外）
```

### 3. 基址寻址（Based）

基址寄存器 + 位移量。

```asm
MOV AX, 10H[BX]    ; EA = BX + 10H
MOV AX, [BX+10H]   ; 等价写法
```

### 4. 变址寻址（Indexed）

变址寄存器 + 位移量，常用于数组。

```asm
MOV AX, ARRAY[SI]  ; EA = ARRAY + SI
MOV AX, [SI+20H]
```

### 5. 基址变址寻址（Based Indexed）

基址 + 变址，可再加位移量，最灵活。

```asm
MOV AX, [BX+SI]        ; EA = BX + SI
MOV AX, 5[BX+DI]       ; EA = BX + DI + 5
MOV AX, [BX+SI+10H]    ; EA = BX + SI + 10H
```

---

## 四、默认段寄存器规则

| 间接寄存器 | 默认段 |
| :---: | :---: |
| BX、SI、DI | DS |
| BP | SS |

可用**段超越前缀**改变默认段：

```asm
MOV AX, ES:[BX]    ; 强制使用 ES 段
MOV AX, CS:[SI]
```

---

## 五、寻址方式对比

| 寻址方式 | 操作数位置 | 典型用途 |
| :--- | :--- | :--- |
| 立即寻址 | 指令中 | 赋初值、常数 |
| 寄存器寻址 | 寄存器 | 高速数据处理 |
| 直接寻址 | 内存（固定地址） | 访问变量 |
| 寄存器间接 | 内存（地址在寄存器） | 指针、动态访问 |
| 基址/变址 | 内存（组合地址） | 数组、表格 |
| 基址变址 | 内存（最灵活） | 二维数组、复杂结构 |

---

## 六、小结

- 立即、寄存器寻址不访存，速度快
- 存储器寻址的 EA = 基址 + 变址 + 位移量的不同组合
- 牢记 BX/SI/DI 默认 DS、BP 默认 SS，可用段超越修改
