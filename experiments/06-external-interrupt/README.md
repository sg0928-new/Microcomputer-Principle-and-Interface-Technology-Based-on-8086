# 实验六：外部中断（8259A + 8255A）

## 一、实验目的

1. 掌握 8259A 的初始化与中断屏蔽操作
2. 学会中断向量的保存、设置与恢复
3. 理解中断服务程序（ISR）的编写规范

## 二、实验原理

外部脉冲信号接到 8259A 的中断请求输入，每来一个脉冲触发一次中断。CPU 响应后转入中断服务程序，在 ISR 中翻转 8255 PA 上的 LED 状态。服务结束发送 EOI 通知 8259A，再用 IRET 返回。

## 三、关键步骤

1. 用 INT 21H 的 35H 保存原中断向量
2. 用 25H 把向量指向自定义 ISR
3. 初始化 8255，解除 8259 对应屏蔽位
4. STI 开中断，主循环用 HLT 等待
5. ISR 末尾发 EOI（`MOV AL,20H / OUT 20H,AL`）并 IRET

## 四、接线表

| 器件 | 连接 |
| :--- | :--- |
| 脉冲源 | 8259 IR 输入 |
| 8259 INT/INTA | 8086 INTR/INTA |
| 8255 PA0 | LED |
| 8259 CS | 对应 20H/21H 译码 |

## 五、实验步骤

1. 连接中断请求与指示电路
2. 运行程序，每按一次脉冲按钮，LED 状态翻转
3. 用 DEBUG 观察中断响应时栈中断点的保存

## 六、思考与扩展

- 若不发 EOI 会怎样？（同级中断无法再次触发）
- 如何实现中断嵌套，让高优先级中断打断低优先级？（ISR 内提前 STI）
