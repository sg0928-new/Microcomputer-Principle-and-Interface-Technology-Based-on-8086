# 8251A 可编程串行通信接口

8251A（USART，Universal Synchronous/Asynchronous Receiver/Transmitter）是可编程串行通信接口，支持同步与异步两种方式，完成并行数据与串行数据的转换。

---

## 一、主要功能

- 异步方式：5~8 位字符，可带 1/1.5/2 个停止位，支持奇偶校验
- 同步方式：5~8 位字符，内/外同步，自动插入同步字符
- 独立的发送器与接收器，全双工
- 自动产生并检测帧格式、校验错误
- 单一 +5V，28 引脚

---

## 二、内部结构

```text
发送缓冲器 ──► 发送移位寄存器 ──► TxD
RxD ──► 接收移位寄存器 ──► 接收缓冲器
读写控制、调制解调控制、状态缓冲
```

| 寄存器 | 作用 |
| :--- | :--- |
| 数据寄存器 | 存放待发/已收数据 |
| 控制寄存器 | 工作方式与命令 |
| 状态寄存器 | 反映收发状态与错误标志 |

---

## 三、关键引脚

| 引脚 | 功能 |
| :--- | :--- |
| TxD / RxD | 发送 / 接收数据线 |
| TxC / RxC | 发送 / 接收时钟 |
| TxRDY / RxRDY | 发送缓冲空 / 接收数据就绪 |
| DTR/DSR、RTS/CTS | 调制解调握手信号 |
| SYNDET | 同步检测 |

---

## 四、方式控制字（方式指令）

### 异步方式字

- D1D0：非 00 表示异步，01/10/11 对应波特率因子 1/16/64
- D3D2：字符长度（5~8 位）
- D4：奇偶校验允许
- D5：偶/奇校验
- D7D6：停止位个数（01=1，10=1.5，11=2）

### 同步方式字

D1D0=00 时为同步，其余位定义同步方式、字符长度、校验等。

---

## 五、命令控制字（命令指令）

写入方式字后写入命令字，控制实际收发：

| 位 | 功能 |
| :--- | :--- |
| D0 TxEN | 允许发送 |
| D1 DTR | 数据终端就绪 |
| D2 RxEN | 允许接收 |
| D3 SBRK | 发送中止字符 |
| D4 ER | 错误标志复位 |
| D5 RTS | 请求发送 |
| D6 IR | 内部复位 |
| D7 EH | 进入同步搜索 |

---

## 六、状态字

读取状态寄存器可判断：

- TxRDY、RxRDY 收发就绪状态
- PE（奇偶错）、OE（溢出错）、FE（帧错）
- DSR、SYNDET 等

---

## 七、编程示例（异步初始化）

```asm
; 端口假设 308H(数据)/309H(控制)
; 内部复位
MOV DX, 309H
MOV AL, 40H
OUT DX, AL

; 异步方式字：8位数据、1停止位、无校验、波特率因子16 → 4EH
MOV AL, 4EH
OUT DX, AL

; 命令字：允许收发、错误复位、RTS/DTR 有效 → 37H
MOV AL, 37H
OUT DX, AL

; 发送一个字符
MOV DX, 308H
MOV AL, 'A'
OUT DX, AL
```

---

## 八、波特率与波特率因子

```text
实际波特率 = 时钟频率 ÷ 波特率因子
```

例：RxC 为 19200Hz，因子 16，则波特率为 1200 bps。

---

## 九、小结

- 8251A 是全双工 USART，支持同步/异步
- 初始化顺序：软件复位 → 方式字 → 命令字
- 状态字反映就绪与三类错误（PE/OE/FE）
- 波特率由时钟与波特率因子决定
