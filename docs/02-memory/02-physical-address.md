# 物理地址计算

## 一、地址加法器公式

20 位物理地址由 BIU 中的地址加法器合成：

```text
物理地址 = 段地址 × 16 + 偏移地址
```

由于 ×16 等价于二进制**左移 4 位**（十六进制后补一个 0），所以也写作：

```text
物理地址 = 段地址左移 4 位 + 偏移地址
```

---

## 二、计算示例

### 示例 1：基本计算

已知段地址 `1234H`，偏移地址 `0056H`：

```text
  12340H      （1234H 左移 4 位 = 12340H）
+ 00056H
────────
  12356H      → 物理地址
```

### 示例 2：取指令地址

`CS = 2000H`，`IP = 0100H`：

```text
20000H + 0100H = 20100H
```

### 示例 3：堆栈地址

`SS = 3000H`，`SP = 0FFEH`：

```text
30000H + 0FFEH = 30FFEH
```

### 示例 4：带进位

段地址 `FFFFH`，偏移 `0010H`：

```text
FFFF0H + 0010H = 100000H
```

> 结果超过 20 位时，最高位（第 20 位）被丢弃，地址在 1MB 范围内回绕。

## 三、常用默认组合速查

| 访问类型 | 段寄存器 | 偏移 | 物理地址 |
| :--- | :---: | :---: | :--- |
| 取指令 | CS | IP | CS×16+IP |
| 堆栈操作 | SS | SP/BP | SS×16+SP |
| 数据（默认） | DS | BX/SI/DI/16位地址 | DS×16+偏移 |
| 串操作源 | DS | SI | DS×16+SI |
| 串操作目的 | ES | DI | ES×16+DI |

---

## 四、段首地址为何要 16 对齐

段地址寄存器只存段首的高 16 位，低 4 位隐含为 0：

```text
段首物理地址 = 段寄存器内容 × 16
```

因此段首地址天然是 16 的倍数，无需额外存储低 4 位，这正是"×16"规则的来源。

## 五、练习与答案

**练习：** 写出下列逻辑地址的物理地址。

| 逻辑地址 | 物理地址 |
| :--- | :--- |
| `2000:1234H` | `21234H` |
| `0ABC:000FH` | `0ABCFH` |
| `1000:FFFFH` | `1FFFFH` |
| `3500:0A00H` | `35A00H` |

---

## 六、小结

- 核心公式：**物理地址 = 段地址 × 16 + 偏移地址**
- 十六进制运算时，段地址后补 0 再与偏移相加
- 牢记各种默认段:偏移组合，是阅读汇编程序的基础
