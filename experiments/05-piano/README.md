# 实验五：电子琴（8253 定时器驱动扬声器）

## 一、实验目的

1. 掌握 8253 方式 3（方波发生器）的编程
2. 理解频率与计数初值的关系
3. 学会用定时器输出不同音阶

## 二、实验原理

8253 计数器 2 工作在方式 3，输出连续方波驱动扬声器。不同音阶对应不同频率，按公式 `N = fCLK ÷ fOUT` 计算计数初值。按下数字键 1~8 时，把对应初值写入计数器，扬声器发出相应音调。

## 三、计数初值

```text
N = 输入时钟频率 ÷ 期望输出频率
```

示例表中初值基于固定输入时钟，实际需根据 Proteus 中 CLK 频率重新计算。

## 四、8253 控制字

计数器 2、先低后高、方式 3、二进制：

```text
10 11 011 0 = B6H
```

## 五、接线表

| 器件 | 连接 |
| :--- | :--- |
| 8253 CLK2 | 固定频率时钟源 |
| 8253 OUT2 | 扬声器（经驱动/隔直电容） |
| 8253 GATE2 | 由 8255 PB 控制门控 |
| 8253 CS | 译码输出 304H~307H |

## 六、实验步骤

1. 连接定时器与扬声器
2. 运行程序，按 1~8 键听不同音阶
3. 修改 NOTES 表，校准音高
